Intro to Python

Course Syllabus

Course Description

Welcome to the Introduction to Python Programming course! This course is designed for beginners who want to learn the fundamentals of Python programming. Throughout the course, you will gain hands-on experience with Python's core concepts and libraries, enabling you to build your own projects by the end of the course. The course is divided into eight modules, each focusing on a specific aspect of Python programming. We will start with basic programming constructs, and progress toward more elaborate programming skills and the use of advanced packages for data science applications.

Course Outcomes

By the end of this course, you will have achieved the following learning outcomes:

  • Understand core Python programming principles and data structures.
  • Develop modular and reusable code.
  • Perform data manipulation and analysis using Numpy and Pandas.
  • Create insightful data visualizations with Matplotlib.
  • Demonstrate proficiency by completing a practical programming project.

Course Materials

  • Allen B. Downey, Think Python: How to Think Like a Computer Scientist, 3rd edition, O'Reilly, 2024.
  • Wes McKinney, Python for Data Analysis, 3rd edition, O'Reilly, 2022

Module Overview

  • Module 1: Variables, Statements, and Functions
  • Module 2: Functions, Interfaces, Conditionals, and Iterations
  • Module 3: Strings and Lists
  • Module 4: Dictionaries and Tuples
  • Module 5: NumPy
  • Module 6: Pandas
  • Module 7: Matplotlib
  • Module 8: Final Project

Course Activities and Assignments

Below are descriptions of major course assignments and activities that will be graded and required in the course.

Guided Practice

These tasks will require you to watch a video demonstration where a faculty expert walks through a relevant problem. After viewing the demonstration, replicate or apply this process to the provided guided practice problem. Submit your work for credit as well as access to the Reveal page that provides the solution and video walkthrough. These will be graded on completion.

Assignments

These weekly assignments will require you to apply concepts and processes to 2 to 4 problems. These will be graded on accuracy.

Quizzes

Check your understanding of the chapter material with a short comprehension quiz. These short reading checks will be graded on accuracy.

Discussion Boards

The best way for you to learn is to be actively engaged in the teaching and learning process. Therefore, there will be an discussion assignment each week. Use this as a space to ask questions and share your ideas about the assignments. These discussion boards will have prompts and will be graded on completion.

Final Project

The Final Project will require you to conduct data analysis using the methods and tools of this course. You will submit this project in the last week of class.

Reflection and Feedback

Each week, you will be asked to reflect on what you have learned and provide feedback on the course. This assignment is designed to help you consolidate your understanding of the material and to give you an opportunity to share your thoughts on the course content and structure.

Course Grading

Assignments 50%
Quizzes 10%
Guided Practice 10%
Final Project 20%
Discussions 5%
Reflection and Feedback 5%
Total 100%
